# HireHub - Job Board Portal

A full-stack Job Board web application built with the MERN stack.

## Features
- JWT Authentication (Register / Login)
- Role-based access — Recruiter & Job Seeker
- Recruiters can post and manage jobs
- Job Seekers can browse, search and apply
- PDF Resume upload on application
- Recruiter dashboard to view applicants and resumes

## Tech Stack
- **Frontend:** React.js, React Router, Axios, Context API
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Auth:** JWT, bcryptjs
- **File Upload:** Multer

## Setup Instructions

### Backend
cd backend
npm install
# Add .env file with MONGO_URI and JWT_SECRET
npm run dev

### Frontend
cd frontend
npm install
npm run dev
